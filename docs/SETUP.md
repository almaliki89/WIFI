
# Setup

1. Install Node.js 20 or newer.
2. Open a terminal in the project folder.
3. Run `npm install`.
4. Run `npm run check`.
5. Run `npm start`.

If PowerShell blocks scripts, use the standard PowerShell terminal and run `npm.cmd install` / `npm.cmd start`.

The native C++ scaffold is optional. The JavaScript app runs without CMake or a compiler.
