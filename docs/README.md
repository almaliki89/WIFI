
# Documentation

WiFiHack3r Lab is an educational simulator. The network entries are fictional and generated by the application. All scenario actions create explanatory events rather than sending network traffic.

## Main components
- `src/desktop/main/main.js`: Electron lifecycle and validated IPC handlers.
- `src/desktop/preload/preload.js`: narrow, context-isolated API.
- `src/desktop/renderer`: interface.
- `src/core`: data models and simulation-only services.
- `src/native`: optional C++ scaffold; not required to launch the app.
